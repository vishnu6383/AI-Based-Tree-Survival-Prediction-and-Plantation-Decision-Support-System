# Tree Survival Prediction System - Frontend

Modern React 19 + Vite web interface for the AI-Based Tree Survival Prediction and Plantation Decision Support System.

## Features
- **Hero & Problem Statement**: Overview of microclimate-aware afforestation with interactive climate preset buttons.
- **Predictive Dashboard**: Climate input sliders, real-time single-species survival probability gauge, risk classification, and transparent botanical reasoning.
- **Top 3 Optimal Recommendations**: Automatic multi-species ranking and selection of optimal matches.
- **Species Explorer**: Botanical catalog with growth rates, rainfall and temperature envelopes, compatible soils, and full plantation guides.
- **Auditing & History**: Filterable history of prediction records with CSV export and clear history capabilities.
- **Methodology & Viva Guide**: ML evaluation metrics, confusion matrix, feature importance charts, and architectural Q&A.

## Development Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
